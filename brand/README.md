# Brand assets

Assets for the "Bíblia lida por elas" channel, drawn with the same code, fonts and palette as the video artwork (`pipeline/template/`).

| File | Use |
|---|---|
| `avatar.png` | YouTube channel avatar, 800x800 (YouTube crops it to a circle) |

To change an asset, edit its `.html` (open it in a browser to preview) and run `node brand/render.js` from the repository root.

# Identidade visual

Peças do canal "Bíblia lida por elas", desenhadas com o mesmo código, fontes e paleta da arte dos vídeos (`pipeline/template/`).

| Arquivo | Uso |
|---|---|
| `avatar.png` | Foto do canal no YouTube, 800x800 (o YouTube recorta em círculo) |

Para alterar uma peça, edite o `.html` correspondente (dá para abrir no navegador para ver) e rode `node brand/render.js` na raiz do repositório.
